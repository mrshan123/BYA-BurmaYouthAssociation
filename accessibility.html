Learning should be accessible.

BYA is working toward WCAG 2.2 AA-aligned accessibility across navigation, content, forms and mobile use.

Keyboard access

Interactive controls should be reachable by keyboard, show a visible focus state and support Escape for dismissible dialogs.

Language & readability

BYA aims to provide clear Burmese and English content, readable typography, meaningful headings and sufficient contrast.

Forms

Forms should use programmatic labels, understandable instructions, clear errors and success states, and only request information that is necessary.

Continuous improvement

Accessibility is an ongoing QA responsibility. BYA should test with keyboard users, screen readers and people using small mobile screens before major public launches.

Feedback: If you encounter an accessibility barrier, contact BYA and describe the page, device/browser and the task you were trying to complete.
